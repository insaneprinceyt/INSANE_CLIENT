Ready in three steps

Open this page in Chrome on your Android device.

  1. Download the APK

    Tap “Download for Android” and wait for the file to finish downloading.

  2. Open and install

    Open the APK from Chrome’s Downloads. If prompted, allow Chrome to install apps, then tap Install.

  3. Open INSANE CLIENT

    Open Instances → Add → Fabric and select Fabric + INSANE CLIENT. This preset supports Minecraft 1.21.11 with Fabric 0.19.2+ and Java 21+.
