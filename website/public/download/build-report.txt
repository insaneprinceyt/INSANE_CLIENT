GRAPHICS-DRIVER FIX
All launch paths now select Turnip only for Qualcomm Adreno on API28+ when the
system-driver preference is off. Mali, unknown and other unsupported GPUs explicitly
disable Turnip. The native loader retains callback libraries after setup failures,
checks missing callbacks/namespaces and falls back to system Vulkan.
