INSANE CLIENT 2.1.1 — Rust installer fix and release picker

CHANGES
- Fixed the early "Resources could not be prepared" error. Native installation
  starts a detached background worker; its true return means startup accepted,
  not completion. The dialog and installation guard now stay active until the
  completion callback. Resource readiness is checked after successful completion.
- Prevented overlapping installs and duplicate completion. Actual download failure
  details are preserved. A completed install creates an instance while the app is
  backgrounded; editor navigation waits until the fragment resumes.
- Rust Edition now opens a searchable release picker with All releases / In INSANE,
  Refresh, preview labels and cached official history from current/legacy Starling.
- The integrated custom v0.7.7 engine for Minecraft26.3 installs inside INSANE.
  Other official APK releases are marked not integrated and have release-info links.
  This does not make every historical engine internally installable, and does not
  install a separate Android app or invent Minecraft Java versions for Rust.
- Existing Rust and Java game folders, accounts, dark mode and removed Hyper Client
  preset are retained. Existing Rust instances can retry Play after updating.
